A paginated table in a card: title, description, detail, columns, rows already rendered (text or any element) and the `Pager` at the bottom. With `onToggle`, the title collapses or expands the table (`collapsed`). The parent holds the page and the collapsed state, and loads the rows; the table only draws. With `details` (one content per row), `openKey` and `onRowClick`, a row expands on click (or Enter) and shows its detail below: the main columns in the row, the rest inside; the parent holds the open row.
