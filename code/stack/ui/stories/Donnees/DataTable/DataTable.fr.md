Un tableau paginé dans une carte : titre, description, détail, colonnes, lignes déjà rendues (du texte ou n'importe quel élément) et le `Pager` en bas. Avec `onToggle`, le titre replie ou déplie la table (`collapsed`). Le parent tient la page et l'état replié, et charge les lignes ; la table ne fait que dessiner. Avec `details` (un contenu par ligne), `openKey` et `onRowClick`, une ligne se déplie au clic (ou Entrée) et montre son détail dessous : les colonnes principales dans la ligne, le reste dedans ; le parent tient la ligne ouverte.
