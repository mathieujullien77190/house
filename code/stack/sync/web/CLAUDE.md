# sync/web – la page de House Sync

Projet Vite + React + TypeScript à part (mêmes conventions que le site : un dossier par composant, Tailwind, alias `@/`, TypeScript strict, ESLint). Compilé dans l'image de House Sync, servi par lui sur le port 8081. Le rendu vient du paquet **`@house/ui`** (`../../ui`) : ici ne restent que les conteneurs.

- `lib/api.ts` : les services de House Sync (connexion, vue d’ensemble, tables, clips, réglages, machine, Docker, réseau, Hue), session par cookie.
- `components/App` : la clé, puis quatre onglets (`Base`, `Disque`, `Machine`, `Docker`), **Base** (les tables de la base, paginées), **Disque** (la liste des clips du disque backup), **Machine** (caractéristiques `SpecList`, réseau (le câble RJ45 et le WiFi : connecté ou non, débit, signal, trafic), pont Hue (joignable ou non, au même niveau que le réseau, seulement si une adresse de pont est réglée), courbes en direct `LineChart` relues toutes les 2 s, camemberts mémoire, processeur et disque, consommation : processeur, caméras PoE, total mesuré) et **Docker** (une fiche par conteneur) ; tous les blocs se replient (`Collapsible` de `@house/ui`), les « Caractéristiques » le sont au départ ; la vue d'ensemble est rechargée toutes les 15 s sauf média ouvert, et un compteur `refreshTick` fait recharger leur page aux tableaux.
- `TableSection` : une table de la base, paginée (20 lignes) et **repliée par défaut, toutes les tables** (le titre déplie ; la page n'est chargée qu'une fois dépliée), une description par table dans `constants.ts` (`DESCRIPTIONS`) ; le rendu des cellules est dans `UI.tsx` (clip ou image → bouton « voir », adresse → lien, horodatage → date, étiquette → pastille).
- Onglet Machine, « Processeur par thread » : repliée par défaut, une petite courbe en direct par thread (`cpu.perThread`, relu toutes les 2 s, 2 minutes d'historique), sous les courbes du processeur et de la mémoire.
- `SettingsSection` : l'onglet Disque, « Réglages de la sauvegarde » : par caméra, le choix des clips gardés (**Toujours / La nuit / Jamais**, `Tabs` ; hors des clips gardés, la détection de mouvement de la caméra est éteinte), quatre **curseurs** « Direct 4K » et « Direct léger », chacun pour le PC (1024 px et plus) et pour le téléphone (moins de 1024 px) (1 à 25 images par seconde, envoyés au relâchement ; seul un curseur dont la valeur a changé est envoyé, et un échec s'affiche), un curseur **« Sensibilité du mouvement »** (de 1 à 5, envoyé au relâchement ; sert quand une caméra rate un passage) et le rythme des images (**30 s, 1, 2 ou 5 min**, `Tabs`), enregistrés tout de suite (`PUT /api/settings`).
- `ClipsSection` : les clips du disque backup, paginés, **une ligne par événement** avec ses deux versions (copie légère H.264 720p et original H.265 4K, un bouton « voir » et la taille de chacune ; `/api/clips` réunit les fichiers `<id>.h264.mp4` et `<id>.mp4` avec `groupClips`).
- `MediaPanel` : le clip ou l'image ouvert, dans le panneau collant de `@house/ui` au-dessus des tableaux ; la vidéo démarre à l'ouverture, Fermer l'arrête, les tableaux ne changent pas de taille.

Développement : `npm install`, `npm run dev` (HTTPS sur 5181 avec le certificat de `data/certs`, services relayés vers House Sync). Vérifications : `npm run typecheck && npm run lint && npm run build`.
