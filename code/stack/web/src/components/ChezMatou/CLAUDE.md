# ChezMatou – la page invité du réseau

`https://<mini PC>:8080/chezmatou?k=<LAN_KEY>` : la **même WebApp**, mais `main.tsx` n'affiche que cette page quand le chemin est `/chezmatou` (l'ancien `/invite` est redirigé par l'API en gardant la query). Mobile d'abord (une colonne, 360 px).

- **Qui y entre** : seulement un appareil du **réseau local** (adresse de la connexion TCP, `api/src/lib/lanNetwork.ts`) **et** qui connaît `LAN_KEY` (`.env` du mini PC). Le Funnel Tailscale ne proxifie que la page invité des caméras (`guest:8090`), jamais l'API : cette page n'est pas joignable depuis internet.
- **La clé** (`lib/lanApi.ts`) : lue dans `?k=`, gardée pour l'onglet (`sessionStorage`), puis **effacée de la barre d'adresse** (`history.replaceState`). Elle part dans l'en-tête `X-Lan-Key`, jamais dans l'adresse d'un appel. Les images n'ont pas d'en-tête : la page échange sa clé contre un **jeton de 60 s** (`GET /lan/token`) qu'elle met dans l'adresse du flux (`/lan/stream/<caméra>?t=`) ; si le flux s'arrête, un nouveau jeton est demandé.
- **Ce que la page montre** (`GET /lan/state`, relu toutes les 5 s), chaque partie **seulement si House Sync l'autorise** (`LanAccess` de `sync/web`, document `lan-access`) : les deux caméras des perruches (`voliere-interieur`, `voliere-exterieur`, flux léger MJPEG, **en portrait** quand House Sync les a réglées ainsi : `RotatedMedia`, comme la WebApp) ; les volets (`ShutterCard` : monter, stop, descendre, sans réglage automatique) ; les lampes par **zone** (`LightsPanel` de `@house/ui` avec `showAll={false}` : les `ZONES` de `../Lights/constants.ts`, allumer ou éteindre, aucun curseur, détecteur ni « Tout allumer » ; **sans la lampe des perruches** : zone « Volière » absente, l'API ne la donne pas, `LAN_EXCLUDED_LIGHTS`) ; les climatisations (`AcUnitCard` avec `withVanes={false}` : marche, consigne, ventilateur ; **mode chaud ou froid seulement** via `modes`, un autre mode déjà réglé reste affiché dans l'état). Rien d'autre : ni clips, ni box, ni TV, ni prise, ni réglages.
- **Agrandir une caméra** (`CameraView.tsx`) : un toucher sur la vignette ouvre la **même vue en grand que la WebApp** (`useBigView` : plein écran, portrait conservé, fermeture, zoom au doigt ; `CameraCard` de `@house/ui` sans frise) ; en grand le direct passe en **4K** (`?quality=hd`, chargé caché avec le léger dessous), refermer revient au léger. Pas de sélecteur L/4K.
- **Problèmes** (`LanProblem`) : sans clé ou clé fausse (401, 429), page coupée (403 « désactivé »), hors du réseau local (403), `LAN_KEY` absente (503), API muette : un message à la place des blocs.
- `UI.tsx` : rendu avec les composants de la WebApp ; `ChezMatou.tsx` : état, sondage, ordres ; `CameraView.tsx` : la caméra agrandie ; `helpers.ts` : `lanRooms`, `lanShutters`, `lanAcUnits` (adaptent la réponse de l'API aux props des composants), `problemOf`.
- Les routes : `../../../../api/src/routes/CLAUDE.md` (« Page invité du réseau »).
