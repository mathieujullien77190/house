# ClipPreview – l'aperçu d'un clip sur la carte

Affiché par la carte de Home (`../HouseMap/CLAUDE.md`, règle d'aperçu commune) quand on choisit l'emoji d'un clip (`../ClipEmoji/CLAUDE.md`). Double clic : le clip se lance dans l'onglet Caméras. Pas de carte sur téléphone.

- Vidéo : `ClipPlayer`, ou `PortraitClip` pour une caméra en portrait. Copie légère H.264 si elle existe (`playablePath`).
- Ligne « caméra · date et heure » : un clic l'ouvre comme le double clic. La note du clip dessous, s'il y en a une.
